# Cataclysm: Dark Days Ahead · 道风主题启动界面

本地制作根：`E:\work\image\cataclysm-dao-ui`。这是本窗口的独立项目目录，与父目录现存 Unity 工程分别管理。上游游戏来源为 <https://github.com/CleverRaven/Cataclysm-DDA>；本地交付仓库与发布远端尚未指定，不因来源链接而推送到上游。

## 本批范围

交付 Python/Tk 原生桌面启动器：启动首页、继续游戏、世界管理、设置、帮助，提供真实存档读取及官方 Windows 游戏进程启动。游戏世界生成、角色创建及游戏内选项由官方游戏窗口完成。此次未修改 C++ 游戏内部背包、战斗 HUD 或地图渲染，主题范围止于启动入口。

文字与操作均原生实现，背景不烘焙文案。正式名保留 Cataclysm: Dark Days Ahead，界面中文为本启动器操作文案。没有复用“五行奇谈”的名称、在线区服、角色等级、邮件或奖励数据。

## 视觉与尺寸

两张主风格来源是 `docs/reference-images/mail-style.png` 和 `team-style.png`，已实际查看并在生成主视觉时作为真实图片输入。另查看参考仓库 `qdao_ui_redesign_v5/01_login_2560x1080.png` 的入口控件层级与配套 README；它只用于入口层级研究，不作为新项目的功能真值或运行素材。源库指定的 `qdao_ui_redesign_v5/UI_SPEC.md` 当前缺失，未恢复旧文件。

采用玉绿、青绿、象牙米白纸绢与细暖金；主按钮和选中态为玉绿金边，正文与输入区保持安静纸面。外围使用现有圆润云纹皮肤，主视觉中保留道家 Q 版大头短身人物、葫芦及克制灯穗，并融入旧车、背包、地图、手电及植被覆盖的废墟，承接游戏生存探索题材。

布局目标为 1920×1080，验证 1600×900 与 1280×720。原生插画为 **1672×941 RGB PNG**，保留原生文件；运行时按窗口 cover 显示属于显示缩放，不能称作原生 1920 或 4K。主功能区与背景人物分开，窗口缩放后文字和控件重新排版。

## 行为合同

| 界面 | 真实行为与状态 |
|---|---|
| 首页 | 启动官方程序；程序未配置、找不到或仍在运行时有明确状态，禁止假成功。 |
| 继续游戏 | 读取所选用户目录 `save/<world>` 下的 `.sav` 或 `.sav.gz`；无存档展示空态。按世界名启动其首个角色存档，不能声称精确选择角色。 |
| 世界管理 | 显示真实目录及存档数量，刷新与打开目录；不删除、不重写存档。世界创建在官方游戏内完成。 |
| 设置 | 浏览游戏 `.exe` 和用户目录，保存启动器文字大小与窗口模式；配置存于本项目 `.local/user/settings.json`。窗口模式只作用于启动器。 |
| 帮助 | 说明原生键盘导航、官方游戏衔接和存档位置，明确功能边界。 |

启动通过参数数组和 `shell=False` 实施，官方已核实参数为 `--basepath`、`--userdir`、`--world`。游戏数据根随 executable 目录，默认独立用户目录位于本项目 `.local/game-user`，避免干扰已有游戏存档。多个角色存于同一世界时，`--world` 由官方逻辑读取首个存档；此限制必须在界面和文档中说明。
